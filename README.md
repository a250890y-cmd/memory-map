# メモリーマップ開発プロジェクト - AI開発体制

本プロジェクトでは、以下の専門職AI社員および共通安全規約に基づいて開発を推進します。

---

## 共通安全規約

> [!IMPORTANT]
> すべての専門職AI社員は以下の行動規約を厳守して作業を行ってください。

1. **参照フォルダの不可侵**
   `reference` フォルダ配下に存在する既存のファイルはすべて読み取り専用です。編集、削除、名前変更、新規追加は絶対に禁止します。
2. **破壊的変更の禁止**
   指示された範囲を超えて、既存ファイルを丸ごと書き直したり大幅に削除したりしないでください。修正は最小限の差分にとどめてください。
3. **スコープの限定**
   1回の指示で作業対象とするファイルは最大3ファイルまでに制限します。依頼されていない機能追加やリファクタリングを独断で行わないでください。
4. **依存パッケージの追加制限**
   新しい外部ライブラリやパッケージを導入する際は、勝手に追加せず、必ず導入理由と影響範囲を提示してユーザーの承認を得てください。
